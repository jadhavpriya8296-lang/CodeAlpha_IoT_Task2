# CodeAlpha_IoT_Task2
Temperature-Based LED Control Using Arduino and TMP36
## Objective
To control an LED automatically based on temperature.

## Components Used
- Arduino Uno
- TMP36 Temperature Sensor
- LED
- 220-ohm Resistor
- Tinkercad Circuits

## Working Principle
The TMP36 sensor measures the temperature and sends an analog signal to Arduino.

- Temperature >= 30°C: LED ON
- Temperature < 30°C: LED OFF

## Software Used
Tinkercad Circuits and Arduino C++
